# KODA project page

A static GitHub Pages project page for KODA, following the same editorial rhythm as modern research project pages: Abstract, Method, Results, Dataset, and Citation. The page uses original HTML/CSS and project-owned media; it does not copy the OMEGA-0 repository.

## Local preview

```bash
python3 -m http.server 4173
```

Open <http://127.0.0.1:4173/>.

## Included project media

- `assets/koda-data/` contains the four paired demonstration clips from `~/Desktop/推送/视频素材/KODA_data/`.
- `assets/figures/` contains the two KODA data-processing figures from `~/Desktop/推送/视频素材/说明框图/`.
- `assets/source.mp4` remains local-only because GitHub rejects files larger than 100 MB; the featured page video uses the compressed KODA task clip instead.
